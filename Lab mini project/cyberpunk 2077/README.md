# 🌆 Cyberpunk Neon Rainy City Visualization

A futuristic **Cyberpunk 3D City Environment** created using **OpenGL** and **GLUT** in C++.

This project demonstrates real-time computer graphics concepts including:

- 🌃 Neon Cyberpunk Lighting
- 🌧️ Rain Particle System
- 🌫️ Fog Effects
- 🚗 Animated Cars
- 🚁 Flying Drone Animation
- 🌞 Day/Night Mode
- 🕒 Real-Time Clock Building
- 🎮 Interactive Camera Controls

# 🎮 Keyboard Controls

| Key | Action |
|---|---|
| W / S | Zoom In / Out |
| A / D | Rotate Scene |
| Q / E | Move Camera Up / Down |
| Arrow Keys | Move Camera |
| R | Toggle Rain |
| N | Toggle Neon Lights |
| T | Day/Night Mode |
| F | Toggle Fog |
| ESC | Exit Program |

# ⚙️ How to Run

## 🖥️ Requirements

- Code::Blocks / Visual Studio / g++
- OpenGL
- GLUT / FreeGLUT

---

## 🔧 Compile

```bash
g++ cyber_city.cpp -o cyber_city -lopengl32 -lglu32 -lglut32
```

---

## ▶️ Run

```bash
./cyber_city
```
